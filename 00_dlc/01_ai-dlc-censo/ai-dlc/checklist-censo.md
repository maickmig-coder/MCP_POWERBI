# Checklist de Censo BI

## 1. Identificación

- [ ] Nombre del BI
- [ ] Nombre del proyecto
- [ ] Objetivo
- [ ] Área
- [ ] Responsable funcional
- [ ] Responsable técnico
- [ ] Tecnología
- [ ] Repositorio
- [ ] Ambiente
- [ ] Versión
- [ ] Fecha del censo

## 2. Fuentes

- [ ] Fuentes identificadas
- [ ] Origen de cada fuente
- [ ] Conexiones identificadas
- [ ] Consultas identificadas
- [ ] Transformaciones identificadas
- [ ] Frecuencia de actualización identificada
- [ ] Propietario identificado, si está disponible

## 3. Modelo

- [ ] Tablas
- [ ] Columnas
- [ ] Medidas
- [ ] Relaciones
- [ ] Cardinalidades
- [ ] Dirección de filtros
- [ ] Claves
- [ ] Jerarquías
- [ ] Granularidad
- [ ] Tablas de hechos
- [ ] Tablas de dimensiones

## 4. Reporte

- [ ] Páginas
- [ ] Páginas ocultas
- [ ] Visuales
- [ ] Slicers
- [ ] Filtros
- [ ] Bookmarks
- [ ] Botones
- [ ] Navegación
- [ ] Tooltips
- [ ] KPIs
- [ ] Tema
- [ ] Colores

## Identificación de visuales
- [ ] Nombre/título de cada visual identificado
- [ ] Visuales sin título identificados como "Sin título visible"
- [ ] Tipo de cada visual identificado
- [ ] Campos/Categorías identificados
- [ ] Medidas identificadas
- [ ] Filtros identificados
- [ ] Propósito/notas identificados

## 5. Elementos utilizados

- [ ] Campos utilizados
- [ ] Medidas utilizadas
- [ ] Tablas utilizadas
- [ ] Relaciones relevantes
- [ ] Trazabilidad campo → visual
- [ ] Trazabilidad visual → página

## 6. Elementos no utilizados

- [ ] Columnas no utilizadas
- [ ] Medidas no utilizadas
- [ ] Tablas sin consumo
- [ ] Relaciones sin uso identificado
- [ ] Consultas sin consumo
- [ ] Parámetros sin uso identificado
- [ ] Visuales sin datos o sin consumo identificable
- [ ] Páginas ocultas revisadas
- [ ] Elementos técnicos clasificados

## 7. Reglas de negocio

- [ ] KPIs
- [ ] Fórmulas
- [ ] Condiciones
- [ ] Clasificaciones
- [ ] Estados
- [ ] Deduplicaciones
- [ ] Homologaciones
- [ ] Tratamiento de nulos
- [ ] Inclusiones
- [ ] Exclusiones
- [ ] Reglas temporales

## 8. Dependencias

- [ ] Fuente → consulta
- [ ] Consulta → transformación
- [ ] Transformación → tabla
- [ ] Tabla → campo
- [ ] Campo → medida
- [ ] Medida → visual
- [ ] Visual → página
- [ ] KPI → regla

## 9. Vacíos

- [ ] Fuentes sin propietario
- [ ] KPIs sin definición
- [ ] Tablas sin granularidad
- [ ] Campos sin descripción
- [ ] Relaciones sin lógica clara
- [ ] Actualización desconocida
- [ ] Dependencias externas desconocidas
- [ ] Responsables desconocidos
- [ ] Orígenes desconocidos
- [ ] Otros vacíos detectados

## 10. Propuestas IA

- [ ] La IA revisó si faltan categorías en el censo
- [ ] Cada propuesta tiene evidencia
- [ ] Cada propuesta tiene motivo
- [ ] Cada propuesta indica impacto
- [ ] Cada propuesta indica si requiere validación
- [ ] No se generaron propuestas genéricas sin evidencia

## 11. Cierre

- [ ] Censo consolidado
- [ ] Hallazgos documentados
- [ ] Limitaciones documentadas
- [ ] Elementos no clasificados revisados
- [ ] Vacíos revisados
- [ ] Propuestas revisadas
- [ ] Validación final completada
