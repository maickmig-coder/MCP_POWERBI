# CONSOLIDACIÓN V5 — REGISTRO DE CAMBIOS

## Incorporación

Se reincorpora formalmente el Registro de Cambio como documento específico
para modificaciones relevantes.

## Elementos recuperados

- Cambio solicitado.
- Motivo/objetivo.
- Estado anterior.
- Propuesta.
- Alcance.
- Dependencias.
- Riesgo.
- Decisión del analista.
- Cambio realizado.
- Estado posterior.
- Validación antes/después.
- Beneficio esperado.
- Beneficio/impacto observado.
- Impacto técnico.
- Impacto funcional.
- Alertas.
- Pendientes.
- Cierre.

## Relación documental

README:
Historia acumulada del tablero.

Registro de Cambio:
Detalle de una intervención específica.

Ambos deben mantenerse.
