# CONSOLIDACIÓN V7 — CENSO PARA DEPURACIÓN/MEJORA

## Regla incorporada

La depuración/mejora de BI existente requiere contexto previo.

Si no existe CENSO:
- bloquear depuración/mejora;
- conservar PBIP original;
- ejecutar el ritual de CENSO;
- guardar el CENSO;
- verificarlo;
- solo después habilitar la depuración/mejora.

## Simetría de procesos

| Proceso | BI existente sin CENSO | Acción |
|---|---|---|
| Modificación | Bloqueado | CENSO + PBIP + verificación |
| Depuración/Mejora | Bloqueado | CENSO + PBIP + verificación |
